# Tutorial: Using survey data for Agent-Based Models in migration research
## Population and Social Data Science Summer Incubator Program.

Material for the tutorial on *Using Survey-based ABM in migration research*. June, 27th, 2023.

This repository contains a series of jupyter notebooks and Julia scripts divided into parts. The first part focuses on a theoretical ABM. The second part focuses on a survey-based ABM. Necessary input data from the Latin American Migration Project data should be requested directly to project administrators (https://mmp.research.brown.edu/).
